# UX direction (from telebirr screenshots)
- Green hero header (#8DC63F) with big balance-style number: "This Month · ETB 1,247" and Ethiopian month ("Meskerem 2019").
- Rounded white cards on light-grey (#F6F6F6) canvas; 12dp radius, soft elevation.
- 4-column quick-action grid under the hero: Transactions · Calendar · Analytics · Scan New.
- Category tiles like the denomination grid: selectable rounded tiles; selected = green 2dp outline + small green badge.
- Bottom nav: Home | Transactions | Calendar | Analytics | Settings, active item = filled icon + dot.
- Primary CTA = full-width rounded button (blue #0088D1 for "Scan New Messages", pale green when disabled).
